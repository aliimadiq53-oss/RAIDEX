# RIDEX Visitor UI

حزمة واجهة الزائر لمنصة رايد إكس للفروسية والتحكيم.

## الهوية البصرية

- الشعار: `ridex-logo.svg`
- الخط الأساسي: `Thmanyah Sans`
- اللون الأساسي: `#8D381F`
- لون التحويم: `#7A2F18`
- الخلفية الفاتحة: `#F5F0E8`
- السطح: `#FDFAF5`
- النص الداكن: `#1C1A17`
- النص الثانوي: `#6B5D4F`
- الحدود: `#DDD5C5`
- لون إبراز ذهبي: `#D9B06A`

ملف `src/index.css` يحتوي على متغيرات Tailwind والـ `@font-face` الخاصة بالهوية. ملف `ridex-welcome.html` هو شاشة الترحيب الأولى.
